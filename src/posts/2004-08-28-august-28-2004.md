<p> I was having problems with my new motherboard (MS-6570: MSI K7N2 Delta-L) recently: the time was too fast! I would syncronize it with the Internet Time feature of Windows XP and within a day or so, it would be a few to several minutes off. I've found a solution: <a href="http://www.dougknox.com/xp/utils/xp_inet_time.htm">Change Internet Time Sync Interval</a>. This program allows you to change how often the Internet Time feature syncronizes with a time server. I also changed the time server to tock.usno.navy.mil because it take less than a second to syncronize  as opposed to 10+ seconds using the default time.windows.com. I set it to syncronize every hour. This may be overkill, but at least I don't have to worry about programs or files being screwed up because they have already been to the future.</p>
